DATABASE: yayasan_cms

================================================================
A. TABEL UTAMA (dari yayasan_cms (1).sql)
================================================================

1.  about_section
    - Konten halaman tentang kami
    - Fields: id, subtitle, title, sub_heading, description, image, button_text, button_link, is_active

2.  appearance_settings
    - Pengaturan tampilan website
    - Fields: id, primary_color, secondary_color, accent_color, font_family, button_style

3.  campaign_main
    - Kampanye utama/featured
    - Fields: id, subtitle, title, background_image, amount_raised, goal_amount, button_text, button_link

4.  campaign_programs
    - Program-program donasi
    - Fields: id, image, category, title, description, amount_raised, goal_amount, beneficiaries_count, donators_count, gallery_images, link_url

5.  campaign_sidebar
    - Sidebar kampanye
    - Fields: id, title, headline, background_image, description, button_text, button_link

6.  cms_settings
    - Pengaturan CMS umum
    - Fields: id, section, title, subtitle, description

7.  events
    - Data acara/kegiatan
    - Fields: id, title, description, event_date, event_time, location, image, is_featured, countdown_enabled, countdown_date

8.  events_header
    - Header halaman acara
    - Fields: id, subtitle, title

9.  faith_header
    - Header pilar iman
    - Fields: id, subtitle, title

10. faith_pillars
    - Pilar-pilar iman (Sholat, Puasa, Zakat, Haji, dll)
    - Fields: id, pillar_name, subtitle, main_image, tab_icon, description

11. feature_section
    - Fitur-fitur website
    - Fields: id, title, description, icon, link_text, link_url

12. hero_section
    - Slider/hero banner
    - Fields: id, title, subtitle, description, image, button_text, button_link

13. permissions
    - Daftar permission/izin
    - Fields: id, module, action, display_name

14. quotes
    - Kutipan/hadits
    - Fields: id, quote_text, author, source

15. quote_settings
    - Pengaturan background quotes
    - Fields: id, background_image

16. roles
    - Role user (super_admin, admin, editor)
    - Fields: id, name, display_name, description, is_system

17. role_permissions
    - Relasi role dan permission
    - Fields: role_id, permission_id

18. service_header
    - Header layanan
    - Fields: id, subtitle, title

19. service_section
    - Data layanan
    - Fields: id, category, title, description, main_image, icon, link_url

20. site_settings
    - Pengaturan website (nama, kontak, sosmed, logo)
    - Fields: id, site_name, site_tagline, phone_primary, email_primary, address, facebook_url, instagram_url, whatsapp_number, logo_light, logo_dark

21. users
    - Data pengguna admin
    - Fields: id, username, email, password, role_id, full_name, phone, photo, last_login

22. KategoriLegalitasAbout
    - Kategori legalitas yayasan
    - Fields: id, jenis_akta, nomor_akta, deskripsi, status

================================================================
D. CARA IMPORT
================================================================

Via phpMyAdmin:
1. Buka phpMyAdmin (http://localhost/phpmyadmin)
2. Pilih database "yayasan_cms"
3. Klik tab "Import"
4. Pilih file SQL yang ingin diimport
5. Klik "Go"

Via Command Line:
mysql -u root -p yayasan_cms < namafile.sql
